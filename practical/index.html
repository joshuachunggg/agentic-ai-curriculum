A Practical Workshop Build Your Agent

Seven modules. Every module, you ship. By the end, Scout — your personal research agent — is yours to deploy.

0 Toy Examples

This course is the hands-on companion to the Agentic AI lecture curriculum. Where that course explains how agents work — the theory, the tradeoffs, the architecture — this one makes you build one. Real code, real tools, a real agent you can run from your terminal.

The build method is deliberate: you use Claude Code (Anthropic's AI coding CLI) to generate the code, then each section unpacks what was built and why. You're not copying and pasting from a tutorial — you're learning to work with an AI coding assistant while understanding the agent patterns underneath. This is how production engineers work in 2026.

Every module ends with a working agent you can run. No partial builds, no "homework exercise left to the reader." By module 7, Scout is a production-grade research agent with real search tools, parallel subagents, guardrails, and an eval suite — ready to customize for any domain you care about.

Prerequisites
  • Python 3.10+ installed
  • Anthropic API key — ANTHROPIC_API_KEY
  • Claude Code CLI — npm install -g @anthropic-ai/claude-code
  • Basic terminal comfort (cd, ls, running Python scripts)
No deep Python experience needed. Claude Code writes the code. You need to understand what it builds — that's exactly what this course teaches.
What you'll build
Meet Scout

Scout is a personal research assistant agent. It's not a chatbot — it's a program that can reason, search, read, remember, and coordinate subagents to answer complex research questions. You'll build it from scratch, one capability at a time, understanding every layer you add.
